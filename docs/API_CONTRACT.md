# VoiceShield - API & WebSocket Event Contract

This document defines the TypeScript-compatible JSON request/response structures and WebSocket streaming event contracts for integration with the VoiceShield Security Console frontend.

---

## 1. REST API Endpoints

### A. Create Security Analysis Session
- **HTTP Method**: `POST`
- **Path**: `/api/v1/analysis/sessions`
- **Request Body**:
```json
{
  "session_id": "VS-2026-000241",
  "caller_name": "Alex Turner",
  "caller_role": "Executive Director",
  "caller_number": "+1 (555) 234-8901",
  "verification_state": "NOT VERIFIED"
}
```
- **Response Body** (`201 Created`):
```json
{
  "session_id": "VS-2026-000241",
  "status": "LIVE ANALYSIS",
  "message": "VoiceShield security session initialized successfully."
}
```

## 2. WebSocket Real-Time Event Stream

- **WebSocket URL**: `ws://localhost:8000/ws/sessions/{session_id}`
- **Heartbeat**: Send `"ping"` string text; server responds `"pong"`.

### Event Payload Schema (`SecurityEvent`)

Every broadcast event conforms strictly to the following JSON schema:
```json
{
  "event_id": "evt-8f12a3bc",
  "session_id": "VS-2026-000241",
  "timestamp": "02:45:04 UTC",
  "event_type": "RISK_UPDATE",
  "source": "RiskFusionEngine",
  "severity": "HIGH",
  "message": "Fused risk score evaluated at 78/100 (HIGH)",
  "confidence": 1.0,
  "metadata": {
    "risk_score": 78,
    "explanation": "Voice Integrity: Strong synthetic speech indicators",
    "pipeline_latency_ms": 325.4
  }
}
```

### Categorical Event Types (`event_type`)

1. `ANALYSIS_STARTED`: Triggered when an audio chunk enters the pipeline.
2. `ASR_UPDATED`: Speech-to-text transcript generated by `faster-whisper`.
3. `SPEAKER_ANALYSIS_UPDATED`: Speaker similarity score generated by `ECAPA-TDNN`.
4. `SPOOF_ANALYSIS_UPDATED`: Synthetic speech probability generated by `Wav2Vec2`.
5. `SOCIAL_ENGINEERING_UPDATED`: Urgency & threat scores evaluated by NLP.
6. `SECURITY_FINDING`: Granular evidence flag (e.g. `FINANCIAL_REQUEST`, `COERCIVE_LANGUAGE`).
7. `RISK_UPDATE`: Fused multi-modal risk score updated by `RiskFusionEngine`.
8. `ANALYSIS_COMPLETED`: Total pipeline completion notification with stage latencies.
9. `ANALYSIS_ERROR`: Graceful error boundary notification if a stage fails.
