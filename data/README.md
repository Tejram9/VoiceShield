# VoiceShield - Data Storage & Assets

This directory serves as the local workspace for storing reference voice samples, evaluation audio files, and temporary processing buffers.

## Directory Organization *(Planned)*

- `samples/reference/`: Enrolled baseline voice embeddings and wav samples for trusted contacts.
- `samples/evaluation/`: Test datasets containing genuine vs. synthetic/spoofed audio clips.
- `temp/`: Temporary audio buffer cache for streaming chunk processing.
